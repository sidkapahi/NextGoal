Straight into OBS

Point it at OBS once. No plugin.

NextGoal writes your goal into a text source over obs-websocket, so it shows up on stream without installing anything into OBS.

  • Connects over obs-websocket, no plugin to install
  • Plain text-file fallback for any setup
  • Creates or reuses the text source for you

Built to sit quietly next to your stream.

A small, focused desktop app. It does one thing and keeps out of the way.

Auto-incrementing

Hit the goal, raise the goal.

Start at zero each stream or sync to your current totals. Every time you reach the number, it steps up by your chosen increment, so there is always a next goal.

No secret to leak.

Twitch uses Device Code Flow with a public client. Your access token is encrypted on your device.

Lives in the tray.

A free-form window with a one-click tray toggle and an idle or live status icon.

Free and open source

MIT licensed, built with Electron and Vue.

No accounts to create, nothing to pay for. Read the code, file an issue, or send a pull request on GitHub.
